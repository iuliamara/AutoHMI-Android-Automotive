# Local Spotify dependency

Run `scripts/setup-spotify.ps1` from the repository root to download and validate the official Spotify App Remote 0.8.0 AAR. The binary is intentionally ignored by Git; no credentials are included here.

https://github.com/spotify/android-sdk/releases/download/v0.8.0-appremote_v2.1.0-auth/spotify-app-remote-release-0.8.0.aar
